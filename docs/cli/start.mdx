---
title: clawdepl start
description: Start a stopped Molty instance.
---

Resume a previously stopped instance.

```bash
clawdepl start <sandbox-id>
```

## Arguments

<ParamField path="sandbox-id" type="string" required>
  The sandbox ID to start.
</ParamField>

## Example

```bash
clawdepl start sandbox_abc123
# ✓ Instance started
```
