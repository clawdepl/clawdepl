---
title: clawdepl account
description: Shortcut alias for `clawdepl auth status`.
---

`clawdepl account` is an alias for [`clawdepl auth status`](/cli/auth#auth-status). All flags are identical.

```bash
clawdepl account [flags]
```

### Flags

| Flag | Description |
|------|-------------|
| `--json` | Output as JSON for scripting |

### Examples

```bash
clawdepl account
clawdepl account --json
```

See [`clawdepl auth status`](/cli/auth#auth-status) for full details.
